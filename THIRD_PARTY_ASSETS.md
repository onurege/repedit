# THIRD-PARTY ASSETS

**None.**

All visual assets in BUSINESS DISTRICT are original, generated procedurally at
runtime from Three.js primitives (`client/src/game/buildings.ts` and friends).
All audio is synthesized at runtime with the WebAudio API
(`client/src/audio.ts`). Fonts are the player's system UI font stack.

| Asset | Author | Source | License |
|---|---|---|---|
| Procedural 3D buildings, vehicles, characters, props | this project | `client/src/game/buildings.ts` | project license |
| Synthesized sound effects & ambience | this project | `client/src/audio.ts` | project license |

Sources such as [Quaternius](https://quaternius.com/) (CC0) and
[Kenney](https://kenney.nl/assets) (CC0) were evaluated and remain good
candidates for future art upgrades; if any external asset is ever added it
must be recorded here with author, source and license.
